Tema de noticias para Tiempo21, portal informativo de la provincia de Las Tunas, Cuba y el mundo.

== Description ==

Tiempo21 es un tema de WordPress moderno y responsivo diseñado específicamente para portals de noticias. Incluye soporte para entradas destacadas, categorización, galerías de fotos, videos de YouTube, reproductor de radio en vivo y mucho más.

== Features ==

* Diseño responsivo y moderno
* Soporte para entradas destacadas (sticky posts)
* Imágenes destacadas con verificación de archivo físico
* Placeholder automático cuando no hay imagen
* Reproductor de audio para radio en vivo
* Contador de visitas por entrada
* Sitemap XML automático
* SEO optimizado (Open Graph, Twitter Cards, JSON-LD)
* Seguridad reforzada
* Código modular con template-parts

== Installation ==

1. Sube la carpeta `tiempo21-radiovictoria/` a `/wp-content/themes/` en tu servidor WordPress.
2. Activa el tema en Apariencia > Temas.
3. Configura las opciones en Apariencia > Personalizar.
